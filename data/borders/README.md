# Границы России и сопредельных стран

Файлы GeoJSON взяты из репозитория `eFrane/admin0`, который содержит данные Natural Earth
Admin 0 в public domain:

- https://github.com/eFrane/admin0
- https://www.naturalearthdata.com/downloads/10m-cultural-vectors/
- https://www.naturalearthdata.com/about/terms-of-use/

В наборе оставлены Россия и её сухопутные соседи. Геометрия используется только для
локального расчёта расстояния до ближайшей границы и не является юридической картой.
