# Участие в разработке Pilot+

Спасибо за интерес к Pilot+. Проект находится в активной разработке, поэтому изменения должны быть небольшими, понятными и проверяемыми.

## Модель веток

- `main` содержит стабильную версию;
- `develop` содержит следующую тестовую версию;
- `feature/<short-name>` используется для функциональности;
- `fix/<short-name>` используется для исправлений;
- `docs/<short-name>` используется для документации.

Рабочая ветка создаётся от актуальной `develop`. Pull request также направляется в `develop`. Слияние `develop` в `main` выполняется только для подготовленного релиза.

## Начало работы

```powershell
git clone https://github.com/Pashadark/pilot-plus.git
cd pilot-plus
git switch develop
npm install
docker compose up -d
npm run dev
```

Перед разработкой прочитайте [гид по проекту](docs/PROJECT_GUIDE.md).

## Проверки

Перед pull request необходимо выполнить:

```powershell
npm run lint
npx tsc --noEmit
npm run build
```

Если существующий технический долг мешает проверке, это нужно явно описать в pull request. Новое изменение не должно добавлять дополнительные ошибки.

## Pull request

В описании укажите:

- что изменено;
- зачем это нужно;
- как проверить результат;
- какие ограничения или последующие задачи остались;
- скриншоты для заметных изменений интерфейса.

Не добавляйте в Git `.env`, секреты, дампы БД, зависимости, build output и сгенерированные Prisma-клиенты.
