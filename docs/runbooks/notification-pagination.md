# Supa Pro: полный счётчик уведомлений

Дата: 19.10.2026.

- Production layout получает `getNotificationPage()`: первые 20 записей и независимый полный счётчик непрочитанных.
- AuditLog считается SQL COUNT с NOT EXISTS по пользовательским квитанциям и областью компаний. Полные записи истории не отправляются в браузер ради счётчика.
- Телематическая история сохраняет существующие права доступа и категории важных событий; для колокольчика доступна вся сохранённая история. Обычный экран событий сохраняет прежнее ограничение периода.
- Курсор содержит время, ключ и границу снимка asOf. Повторные нажатия продолжают тот же снимок; обновление страницы получает новые события.
- «Показать ещё» раскрывает загруженные группы, затем получает очередные 20 записей. Ошибка загрузки не удаляет уже показанный список.
- «Прочитать все» серверно обходит страницы и использует существующие tenant-scoped операции прочтения. События после начала операции не затрагиваются. При частичной ошибке показывается ошибка; повтор безопасен благодаря upsert.
- Полный счётчик не сокращается до 99+. Группировка повторов не уменьшает количество непрочитанных событий.
- Витрина UI-kit без metadata сохраняет локальный режим демонстрационных данных.

Проверки: 47 unit/component-тестов прошли; scoped ESLint прошёл. Глобальный локальный typecheck блокируют существующие ошибки двух Supa Car route-тестов, не связанные с уведомлениями. Production build и браузерная проверка выполняются отдельно при развёртывании.

Production: релиз `20261019-notification-inbox`, blue slot, build/deploy завершён успешно.
