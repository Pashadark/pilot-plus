# Единственное оформление Графит

Изменение от 09.10.2026: варианты Classic, Obsidian и Material исключены из рабочего приложения. Сохранённые значения `pilot-interface` нормализуются в `graphite` до первого отображения страницы. Выбор светлой или тёмной темы сохраняется. Событие storage от старой вкладки не возвращает прежний интерфейс.

Удалены старые scoped-слои globals.css, файл material.css и его импорт; переключатель оформления удалён из меню профиля. На серверном HTML сразу стоит `data-interface="graphite"`.

Проверки перед выкладкой: 12 целевых тестов, TypeScript, scoped ESLint и diff check прошли. Скрипт `.codex-tmp/deploy-graphite-only.sh` собирает отдельный релиз, сохраняет предыдущий и откатывает указатель при ошибке запуска.

Целевой релиз: `/opt/pilot-plus/releases/20261009-graphite-only`. Предыдущий: `/opt/pilot-plus/releases/20261008-workday-tasks`. База данных не меняется. Проверить успешный build, статус службы и фактические цвета в браузере перед подтверждением завершения.

Выкладка завершена: production build и проверка HTTP прошли, получен `GRAPHITE_ONLY_DEPLOY_OK`. На живом сайте desktop body/header/sidebar имеют `rgb(16, 16, 20)`; на ширине 390 px body/header совпадают. В профиле отсутствуют menuitemradio оформления. Светлая тема переключается в `#f4f4f6`, интерфейс остаётся graphite. После проверки возвращена тёмная тема и сброшен тестовый viewport.
