# Карточка штрафа 02Б — 27.09.2026

Утверждённый источник: Figma ODnU4C6ppHiEdqK64ZN4wm, узел 7119:81.

## Реализация

- FineCard.tsx: шапка с суммой и статусом, автомобиль и госномер, водитель, постановление, даты, адрес, действия. Семантические цвета для обеих тем.
- FinesPage.tsx: сохранены фильтры, сетка, платные дороги, выбор и существующая платёжная форма.
- queries.ts: дата постановления и явный timestamp подтверждения менеджером передаются из БД. Галочка не выводится по одному факту наличия имени.
- Кнопка «Место нарушения» открывает адрес и ссылку на поиск карты; это не заявленная точная GPS-точка.
- Кнопка «Водитель» / «Привязать» открывает существующую проверку аренды. Оплата не выполняется автоматически.
- Источник предоставляет фото, не PDF постановления: скачивание подписано «Скачать фото постановления». При отсутствии файла не создаётся ложная ссылка.

## Проверка и выпуск

1. Регрессионные тесты FineCard, FinesPage и queries (13 тестов).
2. ESLint изменённых файлов.
3. Production build в отдельном серверном release до переключения current.
4. Проверка страницы /fines и модальных окон в браузере, без платежей и изменения привязок.

Предыдущий серверный release: /opt/pilot-plus/releases/20260927-queue-health.
Новый: /opt/pilot-plus/releases/20260927-fine-02b-final.
БД и её схема не меняются. Для отката переключить current на предыдущий release и перезапустить pilot-plus.

Локальный общий tsc заблокирован существующими ошибками в output/supapro-design-pack и тестами с BigInt при низком target; не исправляются в косметической задаче. Серверная сборка проверяет deploy-код отдельно.

Проверено в браузере: данные первой карточки, окно кандидатов водителя без подтверждения, адрес, открытие платёжной формы без создания счёта. Оплата остаётся существующей тестовой интеграцией. Мобильная проверка: viewport 390 px, document 380 px, карточка 348 px — горизонтального переполнения нет. Найденное длинное окно привязки ограничено 85dvh с прокруткой и кнопкой закрытия.
