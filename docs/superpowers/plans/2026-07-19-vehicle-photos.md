# Vehicle Photos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Скачать разрешённые фотографии автопарка с autopilotrent.ru, связать их со 130 автомобилями и показать локальные изображения в каталоге и профиле автомобиля.

**Architecture:** Отдельный скрипт синхронизации создаёт версионируемый JSON-манифест и локальные WebP-файлы; обычный seed никогда не зависит от сети. Prisma хранит метаданные `VehicleImage`, server-only queries выбирают главное изображение, а единый клиентский компонент показывает изображение или стабильную заглушку.

**Tech Stack:** Next.js 16.2 App Router, React 19, TypeScript, Prisma 6/PostgreSQL, Tailwind CSS 4, Vitest, Playwright.

## Global Constraints

- Все пользовательские тексты, комментарии и документация — на русском языке.
- Источник изображений: `https://autopilotrent.ru/<city>`; право использования подтверждено Павлом Седовым.
- Фотографии хранятся локально как WebP в `public/vehicles/<city>/<source-key>/`.
- Сопоставление выполняется по городу, модели и порядку одинаковых карточек, без подмены разных экземпляров одним фото.
- Сетевые запросы выполняются только отдельной командой синхронизации, не внутри `db:seed`.
- Повторные синхронизация и seed не создают дубликаты.
- Prisma не импортируется в Client Components.
- Реализация каждого поведения следует циклу RED → GREEN → REFACTOR.
