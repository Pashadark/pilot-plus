# План реализации карточки автомобиля

1. Расширить VehicleDocument nullable-полями приватного файла и применить add-only миграцию.
2. Добавить tenant-scoped загрузку с проверкой сигнатуры, ClamAV и аудитом.
3. Добавить защищённое скачивание из приватного хранилища.
4. Реализовать общий drag-and-drop блок документов для вкладки и редактирования.
5. Перестроить обзор автомобиля по утверждённому варианту 1.
6. Проверить unit-тестами, TypeScript, lint, production build и визуально на реальной Kia Ceed.
