# План реализации ежедневного отчёта по штрафам

1. Добавить и протестировать безопасный HTML-форматтер отдельного отчёта.
2. Создавать отдельные идемпотентные Telegram-задачи в ежедневном запуске 08:00 МСК.
3. При выдаче задачи загружать только неоплаченные штрафы текущей компании, сортировать их и формировать сообщение.
4. Удалить блок штрафов из общей утренней сводки.
5. Обновить тесты постановки и гидратации задач.
6. Запустить модульные тесты, проверку типов и production-сборку.
