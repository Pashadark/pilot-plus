# План реализации редизайна дашборда Pilot+

> **Для агентных исполнителей:** ОБЯЗАТЕЛЬНЫЙ ПОДНАВЫК: использовать `executing-plans` для последовательного выполнения задач. Шаги отслеживаются чекбоксами.

**Цель:** привести desktop-дашборд Pilot+ к утверждённому макету, сохранив существующие карту, мобильный сценарий и авторизацию.

**Архитектура:** `Dashboard` остаётся серверной композицией, визуальные панели разделяются на небольшие типизированные компоненты модуля dashboard. Демонстрационные показатели и ряды графиков остаются в fixtures. Графики строятся локальным SVG без новой зависимости, карта переиспользует текущий MapLibre-клиент.

**Технологии:** Next.js 16.2 App Router, React 19.2, TypeScript 5 strict, Tailwind CSS 4, React Icons, MapLibre GL, Playwright.

## Общие ограничения

- Интерфейс и комментарии в коде только на русском языке.
- Карта — крупнейшая рабочая область desktop и полноэкранная основа mobile.
- Не менять Prisma, авторизацию, MQTT/Redis и продуктовые маршруты.
- Не добавлять chart-библиотеку.
- Использовать семантические CSS variables и общие компоненты Pilot+.
- Сохранить светлую и тёмную темы и клавиатурную доступность.
