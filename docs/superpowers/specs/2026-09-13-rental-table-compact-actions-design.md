# Компактные действия в таблице аренды

## Цель

Заменить текстовую ссылку «Продлить» в столбце действий таблицы аренды двумя явно оформленными компактными кнопками, чтобы пользователь сразу видел доступные операции.

## Интерфейс

- Кнопки располагаются вертикально: «Продлить» сверху, «Завершить» снизу.
- Обе кнопки имеют одинаковую компактную ширину и высоту, не увеличивают строку таблицы чрезмерно и сохраняют удобную область нажатия.
- «Продлить» использует вторичный контурный стиль СУПА ПРО.
- «Завершить» использует более заметный основной стиль, поскольку это следующая ключевая операция активной аренды.
- На узком экране вертикальная компоновка сохраняется без горизонтального переполнения.

## Поведение

- «Продлить» ведёт в блок действий выбранной аренды и сразу открывает форму продления.
- «Завершить» ведёт в тот же блок и сразу открывает форму возврата/закрытия.
- Кнопки показываются только для активной аренды и только когда соответствующая операция разрешена.
- Недоступные операции не имитируются неработающими ссылками.

## Ошибки и доступность

- Элементы имеют корректные доступные названия и видимый фокус клавиатуры.
- Ошибка операции отображается существующим toast-уведомлением без сырого текста Prisma.
- Повторная отправка блокируется существующим pending-состоянием формы операции.

## Проверка

- Компонентный тест проверяет обе кнопки, их вертикальный порядок и адреса прямого открытия операций.
- Проверяются активное и завершённое состояния аренды.
- Выполняются typecheck, тесты модуля аренды и production build.
- После deployment проверяются HTTPS, статус сервиса и отсутствие новых ошибок в журнале.
