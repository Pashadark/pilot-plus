# Подложка загрузки онлайн-карты Supa Pro

## Цель

Показывать спокойный бесшовный паттерн из точек до загрузки клиентского модуля карты и под тайлами MapLibre во время их появления.

## Внешний вид

- Тёмная тема: основной фон `#343438`, нейтральные точки `#686870`.
- Светлая тема: основной фон `#E0EFFF`, нейтральные точки `#9FB5CC`.
- Редкий акцент в обеих темах: `#0067FF`.
- Только маленькие точки: без квадратов, линий, дорог, логотипа, теней и градиентного свечения.
- Геометрия и масштаб паттерна одинаковы в обеих темах.

## Поведение

- Подложка занимает всю область карты во время `next/dynamic` загрузки.
- Тот же фон находится под MapLibre canvas и виден только там, где тайлы ещё не появились.
- После загрузки тайлов карта естественно перекрывает подложку.
- Ошибки карты, элементы управления и данные маршрута не меняются.

## Реализация и проверка

Паттерн создаётся CSS `radial-gradient` в локальном CSS Module без растрового файла и сетевого запроса. Компонент подложки сохраняет `role="status"` и `aria-label="Карта загружается"`. Тест проверяет доступность, применение общего класса и точные цвета обеих тем.
