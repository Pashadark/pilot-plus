# Ночная HTML-сводка и аватар бота СУПА ПРО

## Цель

Ночная автоматическая сводка должна давать Павлу и рабочей группе один понятный план дня: возвраты и выдачи автомобилей, возвраты депозитов, мойки, ТО и автомобили с устаревшим GPS-сигналом. Сообщение отправляется существующим ботом по текущему ночному расписанию и не требует перехода на сайт для понимания основных действий.

## Получатели и расписание

- Сохраняется действующее ночное расписание формирования сводки по московскому времени.
- Одна и та же сводка отправляется в привязанную рабочую Telegram-группу.
- Сводка дублируется в личный чат сотрудника, который привязал рабочую группу, если у него есть активная `TelegramIdentity` типа `STAFF`.
- Для группы и личного чата создаются разные идемпотентные задания, поэтому повторный опрос очереди не создаёт дубликаты.
- Отсутствие личной привязки не мешает доставке сообщения в группу.

## Содержание сводки

В начале показываются дата и краткие счётчики: активные аренды, заявки и свободные автомобили. Ниже идут только непустые операционные разделы:

1. Просроченные действия.
2. Выдачи и подачи автомобилей.
3. Возвраты автомобилей.
4. Депозиты, которые нужно вернуть.
5. Запланированные мойки.
6. Запланированное и просроченное ТО.
7. Автомобили без актуального GPS-сигнала.
8. Свободные автомобили.

Внутри раздела события сортируются по московскому времени. Для аренды выводятся время, действие, номер договора, автомобиль, госномер, ФИО клиента и доступный оператору телефон. Для мойки и ТО выводятся время, автомобиль, госномер и название работ. Для GPS — автомобиль, госномер и время последнего сигнала либо пометка об отсутствии сигнала.

## Telegram HTML

Бот использует только `parse_mode="HTML"`. Markdown-разметка и символы `**` не применяются.

- `<b>` — заголовок сводки, название действия и важные статусы.
- `<i>` — пояснение, дата и второстепенный контекст.
- `<code>` — время, номер договора и государственный номер.
- Эмодзи используются как маркеры разделов: 🔄 возврат, 🚘 выдача, 💰 депозит, 🧼 мойка, 🔧 ТО, 📡 GPS, ✅ свободные автомобили, ⚠️ просрочка.
- Динамические значения обязательно экранируются перед включением в HTML.
- Пустые разделы полностью скрываются.
- Сообщение остаётся компактным; между разделами одна пустая строка, между карточками нет лишних разделителей.

Пример карточки возврата:

```html
<code>20:30</code>  <b>Принять возврат автомобиля</b>
<code>ME-2026-0020-KS</code>
Mercedes-Benz E220d 4Matic · <code>М283АМ997</code>
Клементьев Семен Юрьевич
☎️ +79251479256
```

## Данные и архитектура

Сервер СУПА ПРО остаётся источником данных и формирует готовый безопасный HTML. Гидратор `DAILY_OPERATIONS_DIGEST` расширяется запросами аренды, операций возврата депозита, мойки, ТО и последней позиции автомобиля. Он возвращает `payload.message` и `payload.parseMode = "HTML"`.

Python-бот не собирает бизнес-данные и не форматирует события повторно. Worker берёт готовый текст, проверяет разрешённый режим и вызывает `send_message(..., parse_mode="HTML")`. Для неизвестных старых шаблонов остаётся безопасный текстовый fallback.

GPS считается неактуальным по тому же порогу `OFFLINE_AFTER_MS`, который использует сайт. В сводку попадают только активные, неархивные и не демонстрационные машины компании.

## Ошибки и ограничения

- Ошибка доставки одному получателю не отменяет независимую доставку другому.
- Миграция Telegram-группы в supergroup продолжает обрабатываться существующим повтором на `migrate_to_chat_id`.
- Если расшифровка телефона недоступна, строка телефона скрывается, а сообщение продолжает отправляться.
- Если сводка превышает лимит Telegram, она делится по границам разделов на несколько сообщений с общей нумерацией частей; отдельная карточка не разрывается.
- Ошибка HTML не должна приводить к потере задания: worker повторяет отправку безопасной текстовой версией и фиксирует ошибку в журнале.

## Аватар

Создаётся квадратный PNG 1024×1024 для BotFather: строгий тёмно-синий фирменный фон, контрастный знак «СП», лаконичный автомобильный силуэт и небольшой акцент телематики. Мелкий текст, фотографии, лишние детали и большое количество цветов не используются, чтобы изображение читалось в круглом Telegram-превью.

Файл хранится в `bot/assets/supapro-bot-avatar.png`. Изменение аватара в BotFather остаётся ручным действием владельца, потому что Telegram Bot API не предоставляет метод смены фотографии бота.

## Проверка

- Unit-тесты TypeScript проверяют HTML для каждого раздела, сортировку, экранирование, скрытие пустых разделов и два идемпотентных задания доставки.
- Unit-тесты Python проверяют `parse_mode="HTML"`, доставку группе и личному чату, миграцию группы и fallback при ошибочной разметке.
- Рендер аватара проверяется на размер 1024×1024, квадратное соотношение и читаемость в уменьшенном круглом превью.
- Перед выкладкой запускаются целевые тесты бота, TypeScript typecheck и production build сайта.
