# Массовый импорт документов клиентов из архивов

## Цель

Добавить в существующие карточки клиентов все однозначно распознанные изображения основного разворота паспорта, страницы регистрации и водительского удостоверения из двух предоставленных ZIP-архивов.

## Правила сопоставления

- Клиент определяется по точному сочетанию фамилии и имени из каталога архива и production-базы.
- Опечатка или неоднозначное совпадение не исправляются автоматически: файл остаётся непривязанным и попадает в отчёт.
- Содержимое изображения должно визуально и по распознанному тексту соответствовать имени клиента и заявленному типу документа.
- Файлы из каталога `Не_опознано`, документы автомобиля, ОСАГО и договоры не входят в этот импорт.

## Представление в карточке

- Основной разворот: категория `PASSPORT`, название `Паспорт — основной разворот`.
- Страница регистрации: категория `PASSPORT`, название `Паспорт — регистрация`.
- Водительское удостоверение: категория `DRIVER_LICENSE`, название `Водительское удостоверение`.
- Несколько страниц одного типа хранятся отдельными документами только когда они несут разную информацию; одинаковое содержимое по SHA-256 повторно не загружается.

## Безопасность и атомарность

- Исходники проверяются по сигнатуре и декодируются как изображения.
- Каждый файл сканируется доступным production ClamAV перед переводом в `CLEAN`.
- Файлы размещаются в `PRIVATE_STORAGE_ROOT` и принадлежат пользователю приложения `pilot-plus`.
- Импорт имеет dry-run и apply-режимы, идемпотентен по SHA-256 и не изменяет анкетные поля клиента.
- Перед apply создаётся резервная копия БД и приватного каталога затрагиваемых клиентов.

## Результат

После импорта формируется таблица по всем каталогам архива: найденный клиент, загруженные типы, пропуски, дубликаты и непривязанные файлы. Отсутствующие документы не выдумываются и остаются отмеченными как недостающие.
