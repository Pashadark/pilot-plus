# Ежедневный отчёт по неоплаченным штрафам

## Цель

Каждый день в 08:00 по Москве бот отправляет отдельное сообщение о неоплаченных штрафах. Отчёт не является частью общей операционной сводки.

## Получатели

- Рабочая Telegram-группа компании.
- Привязанный сотрудник, который получает общую утреннюю сводку.

## Состав отчёта

В отчёт входят штрафы со статусами `NEW`, `UNPAID`, `OVERDUE`. Для каждого штрафа показываются:

- фамилия клиента либо «Клиент не назначен»;
- автомобиль и государственный номер;
- нарушение (описание, статья либо «Нарушение не указано»);
- полная сумма и текущая сумма к оплате;
- дата нарушения;
- дата окончания скидочного периода либо отметка, что срок не указан;
- понятный статус штрафа.

Штрафы сортируются сначала по ближайшей дате окончания скидки, затем по дате нарушения. Если штрафов нет, бот всё равно отправляет короткое подтверждение «Неоплаченных штрафов нет».

## Надёжность

Сообщение создаётся отдельной идемпотентной задачей на компанию, дату и получателя, поэтому повторный запуск планировщика не создаёт дублей.
