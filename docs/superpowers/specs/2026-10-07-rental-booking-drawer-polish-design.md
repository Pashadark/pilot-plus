# Полировка окна бронирования

## Цель

Сделать окно нового бронирования визуально понятным и мгновенно отзывчивым, сохранив существующий четырёхшаговый процесс и дизайн-систему СУПА ПРО.

## Утверждённое направление

Пользователь — диспетчер или владелец автопарка, которому нужно быстро оформить бронирование без ощущения громоздкой формы. Главный фокус — текущий шаг и единственное следующее действие. Используются Inter, семантические цвета СУПА ПРО, шаг 4/8 px, белая поднятая поверхность, мягкий серый `elevated`-фон, фирменный синий для текущего действия и зелёный для завершённого шага.

## Поведение

- Крестик и Escape сначала локально скрывают панель, затем выполняют `router.replace` без дополнительного `router.refresh`.
- Шаги представлены четырьмя круглыми маркерами со стрелками между ними.
- Завершённый шаг показывает зелёную галочку, текущий — синий номер, будущие — нейтральные номера.
- На мобильном подписи остаются короткими, а стрелки и маркеры уменьшаются без горизонтального переполнения.
- Кнопка `Новый клиент` находится рядом с поиском, имеет минимальную высоту 44 px и `whitespace-nowrap`; текст не переносится.
- Выбранный клиент получает мягкий синий фон, заметную галочку и компактную метку готовности документов.
- Нижняя панель действий остаётся закреплённой; вторичные действия не конкурируют с основной кнопкой.

## Доступность и состояния

- Диалог сохраняет focus trap, Escape и возврат фокуса существующего `Drawer`.
- Все интерактивные зоны не меньше 44×44 px.
- Текущий шаг имеет `aria-current="step"`; завершённость не передаётся только цветом.
- Переходы используют только opacity и transform, до 220 мс, с учётом `prefers-reduced-motion`.

## Проверка

- Компонентный тест подтверждает мгновенное исчезновение диалога после крестика и единственный `router.replace`.
- Тест шагов подтверждает стрелки, номера и состояние завершённого шага.
- Тест клиентского шага подтверждает однострочную компактную кнопку и открытие формы.
- После тестов выполняются typecheck, lint, production build и визуальная проверка desktop/mobile.
