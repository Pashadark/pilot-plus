# Pilot+

Pilot+ — веб-платформа для управления коммерческим автопарком и транспортной телематикой. Создатель и владелец проекта — **Павел Седов (Pashadark)**.

Сейчас репозиторий содержит интерактивный frontend-прототип, безопасную основу входа администратора и локальную инфраструктуру. Главная страница показывает карту и оперативное состояние демонстрационного парка, `/ui-kit` документирует дизайн-систему, а `/login` выполняет серверную авторизацию. API телеметрии, приём MQTT и real-time обновления ещё не реализованы.

## Маршруты

- `/` — адаптивный центр управления транспортом. На телефоне карта занимает полноэкранное рабочее пространство с поиском, фильтрами и нижней панелью; начиная с `md` используется настольная оболочка, где карта остаётся крупнейшей областью.
- `/ui-kit` — исполняемая витрина компонентов, состояний, токенов и правил применения дизайн-системы Pilot+.
- `/login` — публичная форма входа администратора. `/` и `/ui-kit` требуют действующую серверную сессию.

Карта построена на MapLibre GL и демонстрационных координатах. Тайлы и атрибуция OpenStreetMap подходят для прототипа; production-провайдер, SLA, лимиты и условия использования ещё должны быть выбраны.

## Фактический стек

- Next.js 16.2 App Router, React 19.2, TypeScript 5;
- Tailwind CSS 4 и семантические CSS-переменные;
- MapLibre GL, Framer Motion, React Icons;
- Prisma 6.16, серверные сессии PostgreSQL и Node.js `scrypt`;
- PostgreSQL/PostGIS, Redis и Mosquitto в Docker Compose;
- Vitest, Playwright, ESLint и Prettier для контроля качества.

## Быстрый запуск

Требуются Node.js 20+, npm и, для инфраструктуры, Docker Desktop.

```powershell
npm install
docker compose up -d
npx prisma migrate deploy
npm run db:seed
npm run dev
```

Перед seed скопируйте `.env.example` в `.env` и задайте собственные `PILOT_ADMIN_EMAIL`, `PILOT_ADMIN_PASSWORD` (минимум 12 символов) и `PILOT_ADMIN_NAME`. `.env` нельзя добавлять в Git или выводить в логи.

Приложение доступно по адресу <http://localhost:3000>. PostgreSQL/PostGIS слушает `127.0.0.1:5433`, Redis — `127.0.0.1:6379`, MQTT — `127.0.0.1:1883`, MQTT WebSocket — `127.0.0.1:9001`.

## Команды

```powershell
npm run dev
npm run build
npm run start
npm run lint
npm run typecheck
npm run format:check
npm run test:unit
npm run test:e2e
npm run test:e2e:auth
npm run test:e2e:install
npx prisma validate
npx prisma migrate deploy
npm run db:seed
docker compose ps
docker compose down
```

Playwright использует Chromium и уже запущенный сервер на порту `3000`, если он доступен. Для полного e2e-набора теперь требуется тестовый администратор и подготовка auth-состояния; `npm run test:e2e:auth` последовательно проверяет публичную форму и редиректы гостя без перегрузки dev-сервера. Для Prisma требуется `DATABASE_URL`.

## Правила интерфейса и данных

Компоненты используют семантические токены (`--color-surface`, `--color-text`, `--color-primary` и другие), а не локальные hex-цвета. Светлая и тёмная темы меняют значения токенов на корневом элементе; режим уменьшенного движения отключает обычные переходы. Навигация и действия доступны с клавиатуры, а публичные области касания имеют размер не меньше 44×44 пикселей.

Визуальная система интерфейса использует светлую плотную композицию в стиле Mosaic: компактную навигационную рейку, фиолетовый акцент и плоские информационные панели; продуктовые сценарии и карта остаются собственными Pilot+.

Все автомобили, события, показатели и координаты в текущем интерфейсе — **fixtures**, то есть демонстрационные данные. Они не поступают из PostgreSQL, Redis или MQTT и не должны использоваться как production-источник.
